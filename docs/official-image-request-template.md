## 運用メモ

- 公式サイト上の画像は、明示的な許諾がない限りコピーして利用しない。
- 返信で利用条件・クレジット・期限が指定された場合は `verified-image-sources.json` に記録する。
- 公式画像がないスポットは `kibun_image`、Place ID固定済みで詳細画面だけ実写を見せたいスポットは `detail_google` を使う。
- `detail_google` は一覧・トップ・プラン・記事カードではGoogle Placesを呼ばない。

# Apply v20.11.17

## Smartphone / Codespaces: upload ZIP + script

Upload these two files to the repository root:

- `kibun-v20.11.17-hero-fix.zip`
- `apply_update.sh`

Then run one command:

```bash
git pull origin main && bash apply_update.sh
```

`apply_update.sh` unpacks the ZIP, runs syntax + Hero/Magazine regression checks, stages only this update, commits, and pushes. If a check fails it stops before commit/push.

## If you upload only the ZIP

```bash
git pull origin main && unzip -p kibun-v20.11.17-hero-fix.zip apply_update.sh > /tmp/kibun-apply.sh && bash /tmp/kibun-apply.sh
```
